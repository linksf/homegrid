# Cables & Conduit Runs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace junction-box local/span conduits with selectable **cables** (exposed wires + conduit stub) and **conduit runs** (cream sheathed box-to-box paths), fixing stacked-anchor selection and matching the approved cable design spec.

**Architecture:** New `Cable` and `ConduitRun` domain types with separate layout paths for exposed vs conduit geometry. Render cream runs under boxes and exposed wires over boxes. Wire links restricted to exposed tips; conduit connections imply color-matched continuity. Phased delivery: types → placement → connect → breaker → migration → hub/device cleanup.

**Tech Stack:** Vite, React 19, TypeScript, Vitest, existing SVG canvas (`src/canvas/*`), domain modules (`src/domain/*`).

**Spec:** `docs/superpowers/specs/2026-05-18-cables-design.md`
