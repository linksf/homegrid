# Wirer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive web app for mapping electrical wiring with junction boxes, conduits, wire links, breaker-driven direction propagation, and local persistence with `.wirer` export.

**Architecture:** Domain-first TypeScript model (diagram graph, direction solver) separate from React SVG canvas. Zustand store mutates `Job`/`Diagram`; IndexedDB auto-saves; chevrons and warnings derived from domain state on every render.

**Tech Stack:** Vite, React 19, TypeScript, Zustand, idb, Vitest, @testing-library/react (components)

**Spec:** `docs/superpowers/specs/2026-05-17-wirer-design.md`

```ts
import type { AnchorPosition, JunctionBox } from './types';

export function anchorPoint(box: JunctionBox, anchor: AnchorPosition): { x: number; y: number } {
  const { x, y, width: w, height: h } = box;
  const map: Record<AnchorPosition, [number, number]> = {
    'top-left': [0, 0], 'top-center': [0.5, 0], 'top-right': [1, 0],
    'middle-left': [0, 0.5], center: [0.5, 0.5], 'middle-right': [1, 0.5],
    'bottom-left': [0, 1], 'bottom-center': [0.5, 1], 'bottom-right': [1, 1],
  };
  const [fx, fy] = map[anchor];
  return { x: x + fx * w, y: y + fy * h };
}
```

```ts
    label: 'Breaker panel',

    height: 320,

    name,
    notes: '',

    updatedAt: now,

      junctionBoxes: [breakerBox],
      breakers: [],
      conduits: [],
      wireLinks: [],
      layout: { conduitPaths: {}, wireLinkPaths: {} },
    },
  };
```

- Build adjacency from `wireLinks`.

```ts
export const SCHEMA_VERSION = 1;

export function exportJob(job: Job): Blob {
  return new Blob([JSON.stringify({ schemaVersion: SCHEMA_VERSION, job }, null, 2)], {
    type: 'application/json',
  });
}

export function importJob(json: string): Job {
  const parsed = JSON.parse(json);
  if (parsed.schemaVersion !== 1) throw new Error('Unsupported schema');
  return parsed.job as Job;
}
```
